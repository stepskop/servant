Example site

Built on the servant base image. Every link below is a different feature of servant.conf:

  • /uploads/ — autoindexed, and accepts POST and DELETE
  • /scripts/script.py — CGI through python3
  • /old — a 301 redirect back here
  • /nope — the custom 404 page
